  تحديث أور پاي AurPay — ملف التعديلات (2.zip)
════════════════════════════════════════════════════════════

هذا الملف يحتوي كل التعديلات التي تحوّل مشروعك القديم
(النسخة التي كانت تعتمد على باكند Python) إلى النسخة الجديدة
الخالصة لـ Next.js — الجاهزة للنشر على Vercel مباشرة بدون
أي خادم خارجي.

───────────────
خطوات التطبيق
───────────────

1) فك ضغط 2.zip داخل مجلد المشروع عندك (نفس المستوى الذي
   يوجد فيه package.json) واختر «استبدال / Replace» لكل
   الملفات عند السؤال.

2) شغّل REPLACE.bat مرة واحدة (ويندوز) — أو replace.sh
   (لينكس/ماك). هذا يحذف الملفات القديمة التي ما عادت
   مطلوبة (البروكسي القديم + مشغّل Python + ملفات prisma).

3) شغّل:
       npm install
       npm run dev
   (أو:  bun install ثم bun run dev)

4) افتح المتصفح على:  http://localhost:3000

───────────────
النشر على Vercel
───────────────

- ارفع المشروع إلى GitHub ثم Import من vercel.com/new —
  سيشتغل مباشرة بدون أي إعدادات.
- اختياري (موصى به): أضف متغيرات البيئة:
      GROQ_API_KEY_1  ...  GROQ_API_KEY_5
  (مفاتيح مجانية من console.groq.com/keys) لتشغيل الوكيل
  الذكي الكامل + إدخال الصوت. حتى ٥ مفاتيح تدور تلقائيًا
  عند 429 بدون انتظار.
- بدون أي مفاتيح: التطبيق يشتغل 100% — المساعد الذكي
  يستخدم محرك النوايا العربي المدمج.
